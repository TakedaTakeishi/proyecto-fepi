Posible tala clandestina

Análisis espacial orientado a identificar zonas que presentan pérdida de cobertura forestal y que podrían requerir observación o verificación en campo ante una posible tala clandestina.

Objetivo del análisis

Detectar cambios en la cobertura forestal mediante información geográfica e imágenes satelitales, identificar zonas con pérdida de vegetación y establecer áreas prioritarias para observación y posterior verificación en campo.

El análisis permite generar indicios espaciales sobre posibles actividades de aprovechamiento o pérdida de cobertura, pero no determina por sí mismo la legalidad de dichas actividades.

Fuentes de información

  • Imágenes satelitales Sentinel-2.
  • Cartografía oficial.
  • Información de cobertura forestal.
  • Capas de límites municipales.
  • Información de aprovechamientos forestales.
  • Datos obtenidos mediante Sistemas de Información Geográfica.

La comparación de imágenes de diferentes fechas permite identificar cambios en la cobertura vegetal y localizar zonas donde se ha presentado una disminución de la superficie forestal.

Detección de cambios

El análisis puede realizarse mediante la comparación de imágenes satelitales de diferentes fechas. La disminución de la cobertura forestal permite identificar zonas que requieren un análisis más detallado.

Nivel de cambio Descripción Prioridad
Bajo Cambios pequeños o dispersos en la cobertura. Observación
Medio Pérdida de cobertura que requiere análisis complementario. Revisión
Alto Pérdida significativa de cobertura forestal. Prioritaria
Muy alto Cambio importante y concentrado en una zona. Alta prioridad

Cruce con información territorial

Las zonas donde se detecta pérdida de cobertura pueden relacionarse con otras capas geográficas para determinar si existe información que ayude a explicar el cambio observado.

  • Límites municipales.
  • Predios o polígonos forestales.
  • Áreas con aprovechamiento autorizado.
  • Áreas de conservación.
  • Red vial y caminos.
  • Cobertura forestal.

Priorización para verificación

El sistema puede utilizar los resultados del análisis espacial para establecer prioridades de revisión y seleccionar las zonas que requieren una posible visita de campo.

  1. Detectar pérdida de cobertura forestal.
  2. Delimitar la zona afectada.
  3. Comparar imágenes de diferentes fechas.
  4. Cruzar la información con las capas territoriales.
  5. Identificar si existe un aprovechamiento registrado.
  6. Generar una zona prioritaria para verificación.

Observaciones

La detección de pérdida de cobertura forestal no significa automáticamente que se trate de tala clandestina. El cambio observado puede tener diferentes causas, por lo que los resultados deben considerarse como una herramienta de apoyo para el análisis territorial.

Cuando una zona presente características que requieran atención, se podrá generar una prioridad para su revisión y, cuando corresponda, realizar una verificación en campo.
