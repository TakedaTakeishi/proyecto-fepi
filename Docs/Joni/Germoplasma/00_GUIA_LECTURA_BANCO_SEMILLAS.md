# Guía de lectura — Banco de semillas / viveros (PROBOSQUE)

> Fase: investigación (el alcance del proyecto se define al conocer los 3 procesos: observación de masa forestal, programas de apoyo y banco de semillas).
> Objetivo de esta ruta: entender el funcionamiento interno al 100%, desde roles hasta procedimientos.
> Tiempo estimado: ~2 horas. Rutas relativas desde `Docs/MANUALES/`.

## Lo que NO está en ningún archivo (va a entrevista o solicitud SAIMEX)

- Registros de lotes de semilla y su **trazabilidad** (colecta → beneficio → laboratorio → almacenamiento → siembra → entrega).
- Formatos internos del Laboratorio de Germoplasma (resultados de pruebas, criterios de rechazo).
- Cómo se deciden fechas y zonas de colecta (programación operativa).
- Condiciones físicas de almacenamiento (cámaras de frío, empaque, caducidad).
- Comunicación real vivero ↔ delegación ↔ oficinas centrales (medios, frecuencia, responsables).
- Inventario actualizado de semilla por especie y lote (solo se conoce el agregado: 2.8 t).
